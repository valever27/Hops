# Hops

Hops is a hospitality operations planning system for hotel Food & Beverage teams.

## Goal

Build an MVP for scheduling, availability, contracts, and operational planning.

## Initial scope

- Domain model
- Database schema
- API foundation
- Backend and frontend scaffold
- Scheduling engine foundation

## Repository structure

- `docs/` — product and technical documentation
- `backend/` — API and business logic
- `frontend/` — user interface
- `database/` — schema and migrations
